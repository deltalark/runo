# Provider setup

Runo drives the agent CLIs you already have installed and signed in. It does not sell or proxy tokens.

Install at least one, sign in, and make sure it is on your `PATH`:

- Claude Code: `claude`
- Codex: `codex`
- OpenCode: `opencode`

Open Settings > Providers to see which are detected and their versions. If you install or update a CLI while Runo is open, use Re-detect.

Each agent has its own page under Settings > Agents where you can set a default model, an executable path, extra arguments and environment variables.
