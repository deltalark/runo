A playbook is a `.playbook.md` file: a short header (name, agent, permissions, inputs) and the instructions.

- **Share:** open the playbook and choose **Export to a file**, or keep a folder of them in a git repo.
- **Install:** paste a GitHub repo, a link to one file, a local folder or the clipboard into **Install**. Runo lists what it found and what each asks permission to do before you install it.
- **Update** checks the source again later.
