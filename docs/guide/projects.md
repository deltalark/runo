A project is a folder Runo works in. Add one with **Add a project folder…** in Quick open, or **Add project** in the sidebar. The New project popup can use a folder you have, clone a repository URL into a new folder, or start without code from **Design an app** or **Architecture** (sketch the screens or the system first). **Initialize a Git repository** makes a plain folder a repository, and **Start a session** opens a new session there right away.

Switch projects from the picker in the top bar, or type a project's name in Quick open (**Switch to …**). Right-click a project in the sidebar for **New session here**, **Project notes** and **Edit project…**: its name, color and icon, how you work there (**Crew** or **Direct**), and a **Worktree setup command** that runs in each new isolated worktree, such as `npm install`. **Remove from Runo** forgets the project and its sessions; its folder stays unless you tick **Also delete the project folder from disk**.
