Project notes ({go-notes}, or Notes in the rail's ⋯ menu) is a Markdown notebook for each project: a project list, search, an outline, formatting tools (headings, bold, lists, checklists, quotes, code and links), and **Write**, **Split** or **Preview**. Notes save as you type, and a note can be pinned to the top.

**Share with agents** gives a note to every new session in that project, so agents follow your gotchas, decisions and commands; **Shared with agents** shows which ones they get. Agents can also read and save notes through Runo's tools (see Memory and MCP servers).
