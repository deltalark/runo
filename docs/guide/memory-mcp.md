Runo ships a small MCP server that lets any agent read the session memory, search earlier sessions in the project and save notes ({go-notes} opens Project notes).

**Settings → MCP** lists the MCP servers found in every app on your computer. Share any of them with all agents, or add servers to Runo's own list.
