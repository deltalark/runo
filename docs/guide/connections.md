A connection is a place a session can run besides your machine: Cove on this machine, a Cove server or any SSH server.

1. Add one in **Settings → Connections**.
2. Pick it under **Runs on** when you start a session, or click **Runs on** in a session's header to move it.

Files and the conversation travel with the session. On a Cove or SSH server the agent keeps running after you close your laptop.
