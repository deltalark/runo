title: Switch agents mid-task
keywords: switch agent, hand off, handoff, another agent, codex, claude, second opinion, recap

Hand a session to another agent at any point from the agent picker under the message box. Before anything happens, Runo shows what carries over, what starts fresh and roughly what it costs.

The outgoing agent writes a short recap, and the new agent picks up in the same folder and branch with the same changed files. Switching back is free.
