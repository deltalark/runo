**Changes** shows real git status and diffs for the session ({focus-changes} opens the tab; {panel} shows or hides the panel).

**Review and ship** takes the work through commit, push and **Create PR**. **Git → Changes** on the rail ({go-review}) lists every session with changes waiting, one at a time, beside your folder's own changes. A session's Push and Create PR go through the seatbelt first.
