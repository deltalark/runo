**Changes** shows real git status and diffs for the session ({focus-changes} opens the tab; {panel} shows or hides the panel).

**Review and ship** takes the work through commit, push and **Create PR**. **Review** in the rail ({go-review}) lists every session with changes waiting, one at a time.
