A playbook is a saved task you can run in any project: from **Playbooks** ({go-playbooks}), from quick open, by right-clicking a project, or as a slash command inside the agent.

Write `{{area}}` in the instructions and Runo asks for it before each run. A playbook also says whether it may edit files, run commands or use the network, and Runo holds its session to that.
