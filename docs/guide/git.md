**Git** on the rail ({go-review}) works on the project folder itself, in four tabs: **Changes**, **History**, **Branches** and **GitHub** ({go-reviews}).

- **Sync** brings in the remote's commits and sends yours. A sync, switch, merge or go back can be taken back with **Undo** for a while afterwards.
- **Changes**: tick what to commit, file by file or line by line. A line you leave out stays in your folder for a later commit.
- **History**: the commits as a graph. Pick one to **Ask the agent what this did**, **Go back to this point**, **Start a branch from here**, **Undo this commit**, **Copy to another branch** or **Mark as a release**.
- **Branches**: switch, rename, merge, send or delete branches, and bring back work you set aside. Each agent session's branch is listed with a link to its session.
- **Clashes**: when a sync or merge stops on clashes, pick **Keep yours**, **Keep theirs** or **Keep both** at each spot, or let the agent write a version and **Use it**. **Call it off and put everything back** undoes the whole step.
