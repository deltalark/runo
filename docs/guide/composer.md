---
title: Talk to the agent
keywords: composer, message, mention, @, attach, image, model, effort, permission mode, queue, send
shortcuts: focus-composer
---
Type what you want changed in the message box ({focus-composer} puts the cursor there).

- Mention files with `@` and attach images.
- Pick the model, effort and permission mode below the box. They are read from the agent's own CLI.
- Type your next message while the agent works and it is queued.
- Enter sends and Shift+Enter adds a line (change it in **Settings → Chat**).
