When any agent needs a permission, has a question or wants a plan approved, a card pops up in the corner of the window. Answer it without leaving what you're doing.

Everything waiting is also in the **Inbox** ({go-inbox}). How long an agent waits for an answer is set in **Settings → Chat**.
