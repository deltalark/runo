Each project works one of two ways. **Direct** is the classic way: you start and run sessions yourself. In **Crew**, you talk to one chat per project. Crew answers what it can and starts threads for the work. Each thread is an ordinary session.

- Pick the way when you add a project (**How you work here**), or switch any time from the project menu in the top bar.
- Open Crew from the **Crew** row at the top of the project's sessions, or with **Open Crew** in quick open.
- The chip over Crew's composer decides where a message goes. **Auto** lets Crew choose, **Just answer** means it starts nothing, and **New thread** starts a thread with your message, without asking Crew. Type `@` and a thread's name to send that thread a message directly.
- Crew starts at most 3 threads at once. If it asks for more, a card lets you start the rest or leave them.
- Each thread runs in its own worktree unless Crew says otherwise, keeps a checklist, and reports back. The **Threads** panel beside Crew's chat shows them all.
- When a thread needs a decision, it shows in the corner, in the Inbox and on Home. Pick an answer, or reply in the thread.
- Crew only reads the project. It never changes code itself.
